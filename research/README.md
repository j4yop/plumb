# Research trail

This folder is the record of how the project was decided, kept deliberately. It is not
documentation of the software — it is documentation of the reasoning.

| File | What it is |
|---|---|
| `council/dossier-20261112.md` | The evidence dossier the first council worked from: competition structure, judging rubric, the data audit, the prior-art map, seven candidate project ideas |
| `council/responses-20261112.md` | The five advisors' scored responses to that dossier |
| `council/verdict-20261112.md` | The chairman's verdict: the project concept, the build plan, the risk register |
| `council/report-20261112-v2.html` | The visual report of that deliberation |
| `council-transcript-20261112-2104.md` | The full transcript: dossier, five advisor responses, three peer reviews, synthesis |
| `council-report-20261112-2104.html` | The visual report of that round |

**Note on names.** The first round chose the working title *Certifying Football Claims From
Incomplete Tracking*. A second council round, with the constraint of one word and five or six
letters, reduced it to **PLUMB** — see [`../docs/PROJECT.md`](../docs/PROJECT.md) for the name and
the reasoning behind it. The name changed; the reasoning did not.
