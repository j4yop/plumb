# Nothing leaves the machine, and the match data is never committed

The terms forbid uploading the competition's videos, datasets or extracts to any third-party
hosted or cloud-based model. The pipeline therefore has no model and no network calls at all, and
the repository contains no match data: `MANIFEST.sha256` carries the checksums so a reviewer can
verify their own download, and the public repository can be made without redistributing anything
the terms protect.
