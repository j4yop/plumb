# The public five minutes are a check, never a tuning set

The organisers say it and we hold to it: the public ground truth is for checking that the pipeline
is aligned and for understanding their label semantics, not for choosing between versions of the
system. It matters here because the public score would have chosen a *worse* system — a two-second
episode threshold scores higher on the public window (0.5286 against 0.4824) while producing
eleven possessions where the organisers have seventeen. Parameters are chosen by the football
rule that defines them and by full-match statistics, and the public window is used to check that
both are right.
